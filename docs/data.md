                                     Laptop Auto Sleep Off

                              "Do Nothing" option ko zabardasti enable karne ke liye:

                              powercfg -setdcvalueindex SCHEME_CURRENT SUB_BATTERY BATACTIONCRIT 0

                              (Is mein 0 ka matlab hai 'Do Nothing')

                              Is setting ko foran apply (active) karne ke liye:

                              powercfg -setactive SCHEME_CURRENT
